KitKat ARMv7

A real ARM browser emulator needs an ARM CPU runtime and Android's matching Goldfish virtual hardware. This is the isolated development area for that port.

Backend not ready

This page does not boot Android yet. The ARM QEMU/WebAssembly backend has not been built or tested. No fake Start button is shown.
